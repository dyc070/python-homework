My homework question aims to assess how well someone can create the commonly seen triple slash used in baseball using Python code. The student will have have to input values that used to caculate batting average, on-base percentage, and slugging percentage. This topic assesses their ability to apply arithmetic and to be able to create custom variables. They then also have to turn numerical values into strings and print them in the same format that a triple slash has in a baseball game. So this means including slashes in between each value, which show shows their ability to make strings with characters as well. I have also included an additional challenge which is rounding each value to 3 decimal points. This is something I had to learn my self: I learned the round command from this stackoverflow forum:https://stackoverflow.com/questions/3380484/how-can-i-put-an-actual-backslash-in-a-string-literal-not-use-it-for-an-escape>. I think the most challenging part will be keeping track of many different variables needed for these calculations. Such as hits, walks, at-bats. doubles, singles, etc. With so many variables, it can be easy to accidentally use the wrong variable or do the wrong calculations. I think for someone like me who loves math and baseball it was a very fun challenge and makes learning more fun.
